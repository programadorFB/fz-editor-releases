# FZ Editor

Instaladores do FZ Editor para Windows 10/11 (64 bits).

**[Baixar a versão mais recente](https://github.com/programadorFB/fz-editor-releases/releases/latest)**

## Como instalar

1. Na página da versão, baixe **todos** os arquivos para a mesma pasta: o `FZ-Editor-Setup-x.y.z.exe` e todas as partes `.bin`.
2. Rode o `.exe`. Se o Windows avisar "editor desconhecido", clique em *Mais informações* → *Executar assim mesmo*.
3. Confira a placa de vídeo na página **Sua placa de vídeo**.
4. No fim, entre com a **sua** conta Claude no navegador.

Precisa de ~13 GB livres no disco (mais ~5 GB numa placa NVIDIA).
